热身

羽毛球出现就点它，一共 4 次。量一下你点屏幕有多快，比赛时会把这点时间还给你。

手柄用法

没有连上手柄。用蓝牙或 USB 连上后，按手柄上任意一个键。

启动（他一击球就按）A　或　RB 选 1 / 2 / 3（三条线从左到右）X / Y / B 回中：每推一下，从现在那一格往前后左右挪一格左摇杆或十字键 抢中间那一格按下左摇杆（L3） 下一分 / 开始 / 看成绩Start（＋） 切换视角Select（－）或 LB 选关页：移动 / 确定 / 返回十字键 / A / B

回中（4 级起）：往前推一下 = 往网前挪一格，往后拉一下 = 往后场挪一格，左右同理；比如打完站在后场右边，按 ↑ 再按 ← 就回到正中间。5–7 岁只分前 / 中 / 后三格，只看前后。1–3 级自动回中、自动启动，不用按。PS 手柄 A = ✕、B = ○、X = □、Y = △；Switch Pro 手柄按位置算（右边那个是 A）。

提示：iPhone / iPad 在微信里打开可能读不到手柄，换 Safari 或 Chrome 打开。手柄不会震动，他击球的提示还是看画面、听声音。

按键测试

电脑键盘

不用开模拟也能玩：空格 = 启动（7 级起），1 / 2 / 3 = 选线，方向键每按一下挪一格（4 级起回中用），C = 直接回正中间。

电脑上没有手柄？

打开后：J = A，K = B，U = X，I = Y，Q = LB，E = RB，Enter = Start，Backspace = Select，W A S D = 十字键（抢位），F = 按下左摇杆。打开时空格、1 / 2 / 3 照样能用。

学习路线

每一页球路按游戏里的表现分五级点亮：1 认得 → 2 会选 → 3 选得快 → 4 会抢位 → 5 能打完整。点一页看差在哪。

每页右上角小圆圈里的数字 = 这一页现在亮到第几级（1–5），不是次数。比如「2」= 会选：这页的球选过至少 3 次、七成以上选对了。没有圆圈 = 游戏里还没碰到这一页的球。

👤 玩家和进度

每个玩家的星数、学习路线、跨局对比、复盘都分开存。握拍手决定哪边是反手：4 级起对手会压你的反手后场，在那里击球也更容易失误（5–7 岁不分）。进度只存在这台设备的这个浏览器里：换设备、换浏览器或清理浏览器数据之前，先备份。

备份 / 恢复

备份 = 把所有玩家的进度存成一个文件；到新设备上点「恢复」选这个文件就回来了（同一个玩家会被备份里的进度替换）。
