Pose CLI — l'analyse du mouvement open source pour le travail sérieux.

Une boîte à outils installable via pip qui transforme les données de squelette 3D en analyses sportives exploitables. Conçue pour les scientifiques du sport, les entraîneurs et les analystes de la performance — avec plus de 20 outils intégrés, des plugins par sport et un backend local qui s'exécute entièrement sur votre machine.

Conçu pour celles et ceux qui étudient le mouvement

Trois groupes que nous entendons le plus.

Scientifiques du sport et chercheurs

Réalisez des analyses reproductibles d'une séance et d'un athlète à l'autre. Exportez en Markdown / JSON pour vos articles et rapports. Publiez vos outils comme paquets pip indépendants.

Entraîneurs et analystes de la performance

Évaluez la technique, suivez les progrès, comparez les athlètes. Des outils spécifiques pour le badminton, le sprint et plus encore — installez seulement ce dont vous avez besoin.

Programmes d'EP et laboratoires

Statistiques de mouvement normalisées pour des cohortes d'élèves. Traitement par lots, sortie JSON adaptée à l'IC. Zéro dépendance cloud — toute l'analyse s'exécute en local.

Fonctionnalités clés

Tout ce dont vous avez besoin pour passer des données de pose brutes aux informations exploitables.

🏃 Sports comme plugins

freeplay et sprint intégrés. Installez des paquets par sport : pip install pose-platform[badminton]. Créez le vôtre avec pose sports create.

🖥️ Backend local intégré

pose serve transforme votre ordinateur en backend complet pour Pose Coach — téléchargement automatique, analyse, chat IA, plans d'entraînement. Sans cloud.

🏷️ Annotateur web

Annotez les enregistrements dans votre navigateur avec vidéo synchronisée + superposition du squelette 2D. Créez une vérité terrain pour la calibration et la validation.

🤖 Analyse par LLM

pose chat vous permet de poser des questions en langage naturel sur vos données. DeepSeek par défaut (gratuit). Compatible Claude et Qwen.

📊 Plus de 20 outils d'analyse

Statistiques, segmentation de mouvement, détection d'actions, profilage de vitesse, analyse de la foulée, extraction de temps forts — interface CLI cohérente.

🔒 100 % local

Vos données ne quittent jamais votre ordinateur. L'analyse, le chat IA et le backend local s'exécutent tous sur votre machine. Cache intégré pour des ré-exécutions instantanées.

Architecture

Un CLI Python local avec des sports enfichables et un backend intégré.

  • Plus de 20 outils d'analyse enfichables — statistiques, segmentation de mouvement, détection d'actions, profilage de vitesse, etc.
  • Sports comme plugins — freeplay + sprint intégrés ; installez badminton, basketball, ou créez le vôtre via les entry_points Python
  • Backend léger intégré — pose serve transforme votre ordinateur en backend complet pour Pose Coach ; analyse, coach IA, plans d'entraînement et rapports s'exécutent localement
  • Annotateur Web — pose annotate serve ouvre une interface navigateur avec vidéo + squelette synchronisés pour l'annotation
  • Chat LLM — pose chat avec DeepSeek (par défaut, gratuit), Claude ou Qwen
  • Format JointData3D — format squelette unique partagé avec Pose Coach ; accepte CSV et .bin
  • 100 % local — aucun serveur requis pour les commandes d'analyse

Format de données

Apportez vos propres données de pose — Pose CLI fonctionne avec notre CSV compact à 12 colonnes.

timestamp, joint, wx, wy, wz,
mx, my, mz,
ldq_x, ldq_y, ldq_z, ldq_w

Le binaire .bin de Pose Coach est aussi accepté nativement. Sortie sous forme de rapports Markdown ou de JSON adapté à l'IC. Compatible avec ARKit, OpenPose, MediaPipe et la capture de mouvement.
